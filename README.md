# Aqua-lab（叩き台）

アクアリウムの記録管理Webアプリ。植物アプリ Verdant Log 2（plant-app2）をベースに作成。
GitHub Pages でそのまま公開できる（ビルド不要）。データは端末の中（IndexedDB）に保存。

## できること
- 水槽の追加・編集（種類・水量・立ち上げ日・水換え間隔・換水量・写真・メモ）
- 生体の追加・編集（分類→種類から選択／自由入力・呼び名・数・オスメス・迎えた日・写真・メモ・水槽の移動）
- 水槽の状態（最新の水質・水温の注意・状態タグ）／生体の状態（最新の状態タグ）
- 記録：水換え（換水量）・給餌／投薬（名前と量。過去の名前から選べる）・水質測定（水温・pH・アンモニア・亜硝酸・硝酸塩・KH）・フィルター掃除・掃除・様子メモ・その他
- カレンダー（内容ごとの色の点・水換え予定の輪）・日ごとの記録
- 機器の管理（ヒーター・サーモ・フィルター・ろ材など。手入れ・交換の間隔と次回の予定、「今日 手入れした」ボタン）
- 薬浴の経過管理（症状・薬・対象の生体・予定日数・薬の追加間隔。何日目か・今の様子・次の薬の追加日、終了と結果）
- 水換えのおすすめ（予定日の超過／亜硝酸・アンモニア・硝酸塩の値から判断）
- 水質グラフ（適温の帯・硝酸塩の上限線・水換えした日の印）
- 状態タグの管理（水槽用・生体用）・テーマ・バックアップ

## ファイル構成
```
index.html              画面の骨組み（読み込む順番もここ）
css/                    見た目（基本・共通部品・画面ごと）
js/core/                データと計算（定数・カタログ・保存・写真・水換えの判断など）
js/ui/                  共通の動き（アイコン・重ねる画面・スワイプ・キーボード・部品）
js/features/            画面・機能ごと（1ファイル＝1画面または1機能）
js/main.js              起動
icons/                  ホーム画面のアイコン
images/                 魚の切り抜き（白・透過）とヘッダーの模様（tools/make_header_pattern.py で作成）
tools/build.py          動作確認用に1ファイルへまとめる（dist/aqua-lab-preview.html）
```
